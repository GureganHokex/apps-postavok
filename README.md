# Менеджер прайс-листов пива

Приложение на Python для анализа прайс-листов пива и формирования заказов.

## Возможности

- Загрузка прайс-листов в форматах Excel, PDF, TXT
- Автоматическое распознавание структуры прайс-листов с помощью ML
- Анализ типов пива и тары (кеги, банки, бутылки)
- Определение объема продукции
- Формирование заказов с экспортом в Excel или текстовый формат
- История заказов

## Требования

- Python 3.13+
- Установленные зависимости из requirements.txt

## Быстрая установка

### macOS (РЕКОМЕНДУЕТСЯ!):

**Вариант 1: Автоматическая установка**
```bash
./setup.sh
```

**Вариант 2: Быстрый запуск через .app файл**
1. Дважды щелкните на `BeerOrderManager.app` в Finder
2. Готово!

**Вариант 3: Командная строка**
```bash
./start.sh
```

### Linux:

```bash
# 1. Установите зависимости
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. Запустите приложение
./start.sh
```

### Windows:

```cmd
# 1. Установите зависимости
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# 2. Запустите приложение
start.bat
```

### Детальные инструкции:
См. файл `INSTALL.md` для подробной информации по установке и решению проблем.

## Структура проекта

```
beer_order_app/
├── main.py                    # Точка входа
├── src/                       # Исходный код
│   ├── gui/                   # Интерфейс (Tkinter)
```

## Использование

1. **Загрузка файла**: Перейдите на вкладку "Загрузка файла" и выберите прайс-лист
2. **Обучение** (опционально): Разметьте примеры для улучшения распознавания
3. **Создание заказа**: На вкладке "Создание заказа" выберите позиции и укажите количество
4. **Экспорт**: Сформируйте файл заказа в нужном формате

## Особенности

- **ML распознавание**: Модель Random Forest для автоматического определения типов колонок
- **Анализаторы**: Определение стилей пива и типов тары
- **Гибкий экспорт**: Excel для Excel-входов, текст для остальных форматов

## Ограничения текущей версии

- Google Таблицы не поддерживаются (будет добавлено в следующей версии)
- Для обучения ML модели требуется минимум 10-15 размеченных примеров
- Распознавание PDF может быть неточным для сложных макетов
