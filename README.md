# Пивной импортер - MVP веб-приложение

Веб-приложение для баров, которое принимает прайсы от поставщиков (PDF, Excel, Google Sheets), автоматически извлекает данные о пиве, позволяет формировать заказ и экспортировать его обратно в исходный формат.

## Структура проекта

- `backend/` - Django REST API приложение
- `frontend/` - React SPA приложение

## Установка и запуск

Скопируйте `.env.example` в `.env` в корне проекта и при необходимости в `backend/` и `frontend/`, затем задайте переменные (секреты, домены).

### Backend

1. Перейдите в директорию backend:
```bash
cd backend
```

2. Создайте виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Выполните миграции:
```bash
python manage.py migrate
```

5. Создайте учётную запись администратора (обязательно для входа в админ-панель):
```bash
# В production задайте ADMIN_PASSWORD в переменных окружения
export ADMIN_USERNAME=admin   # по умолчанию
export ADMIN_PASSWORD=ваш_секретный_пароль
python manage.py create_admin_user
```
В production обязательно задайте `ADMIN_PASSWORD` в окружении; в коде пароль не храните.

6. Запустите сервер разработки:
```bash
python manage.py runserver
```

Backend будет доступен по адресу: http://localhost:8000

### Frontend

1. Перейдите в директорию frontend:
```bash
cd frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер разработки:
```bash
npm start
```

Frontend будет доступен по адресу: http://localhost:3000

## Авторизация и роли

- **Админ-панель**: отдельная страница (в production — `admin.html`; в dev — `http://localhost:3000/?page=admin`). Вход только для пользователя с ролью «Администратор». Полный доступ: загрузка файлов, парсинг, заказы, краны, поставщики, статистика.
- **Основное приложение** (http://localhost:3000): вход для бармена и пользователя.
  - **Бармен**: краны (просмотр и редактирование ротации), история заказов (только просмотр на сайте, без скачивания).
  - **Пользователь**: краны (просмотр и переключение видимости кранов).

Дополнительных пользователей (бармен, пользователь) можно создавать через Django Admin (`/admin/`) и назначать им роль в разделе «Профили пользователей».

## Использование

1. Откройте приложение в браузере (http://localhost:3000) или админ-панель (`/?page=admin`).
2. Войдите под учётной записью администратора (см. шаг 5 установки backend).
3. Загрузите файл с прайсом (PDF, Excel или ZIP архив).
4. Запустите парсинг файла.
5. Просмотрите распарсенные позиции в таблице.
6. При необходимости отредактируйте позиции.
7. Выберите позиции для заказа и укажите количество.
8. Создайте заказ и экспортируйте его в нужном формате.

## API Endpoints

- `POST /api/auth/login/` — вход (тело: `username`, `password`). Все остальные запросы требуют сессионной авторизации.
- `GET /api/auth/me/` — текущий пользователь и роль.
- `POST /api/auth/logout/` — выход.
- `POST /api/upload/` — загрузка файла (только админ)
- `POST /api/files/<id>/parse/` - запуск парсинга файла
- `GET /api/files/<id>/items/` - список позиций файла
- `GET /api/files/<id>/metadata/` - метаданные файла
- `PATCH /api/items/<id>/` - редактирование позиции
- `POST /api/orders/` - создание заказа
- `GET /api/orders/<id>/export/` - скачивание экспортированного заказа

## Особенности

- Парсинг PDF файлов (включая сканы с OCR)
- Парсинг Excel файлов (.xls, .xlsx)
- Поддержка Google Sheets (через CSV экспорт)
- Автоматическая фильтрация контактов и служебных данных
- Нормализация данных (единицы измерения, валюты, форматы)
- Редактирование позиций в интерфейсе
- Экспорт заказов в PDF и Excel
