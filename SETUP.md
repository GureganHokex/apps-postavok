# Инструкция по установке и запуску

## Требования

- Python 3.13 или выше
- pip (менеджер пакетов Python)

## Установка

1. Откройте терминал в директории проекта

2. Создайте виртуальное окружение (рекомендуется):

```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:

**Linux/macOS:**
```bash
source venv/bin/activate
```

**Windows:**
```bash
venv\Scripts\activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

1. Перейдите в директорию beer_order_app:

```bash
cd beer_order_app
```

2. Запустите приложение:

```bash
python main.py
```

## Использование

1. **Загрузка файла**: 
   - Откройте вкладку "Загрузка файла"
   - Нажмите "Выбрать файл" и выберите прайс-лист (Excel, PDF или TXT)
   - Дождитесь загрузки и нажмите "Анализировать прайс-лист"

2. **Обучение модели** (опционально):
   - Перейдите на вкладку "Обучение"
   - Загрузите примеры прайс-листов и разместите их
   - После разметки 10+ примеров нажмите "Обучить модель"

3. **Создание заказа**:
   - Откройте вкладку "Создание заказа"
   - Нажмите "Обновить" для загрузки позиций
   - Выберите нужные позиции и укажите количество
   - Нажмите "Создать заказ" и сохраните файл

4. **История заказов**:
   - Пенин ерейдите на вкладку "История" для просмотра ранее созданных заказов

## Зависимости

Приложение использует следующие библиотеки:

- **pandas** - работа с данными
- **openpyxl** - работа с Excel файлами
- **pdfplumber** - парсинг PDF
- **scikit-learn** - машинное обучение
- **sqlalchemy** - работа с базой данных
- **tkinter** - графический интерфейс (встроен в Python)
