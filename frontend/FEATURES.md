# Новые функции и улучшения

## ✅ Внедренные функции

### 1. История заказов
- Компонент `OrdersHistory` со списком всех созданных заказов
- Фильтрация по дате и поиск
- Просмотр деталей заказа в модальном окне
- Повторное скачивание экспортированных файлов
- Статистика по заказам

### 2. Массовые операции
- Компонент `BulkActions` для массовых операций
- Массовое редактирование позиций (цена, валюта, остатки)
- Изменение цены на процент или фиксированную сумму
- Массовое удаление позиций
- API эндпоинты: `/api/items/bulk_update/` и `/api/items/bulk_delete/`

### 3. Клавиатурные сокращения
- `Ctrl+F` - фокус на поиск
- `Ctrl+S` - сохранить текущее редактирование
- `Escape` - отменить редактирование или закрыть меню
- `Ctrl+1-5` - переключение между вкладками
- Хук `useKeyboardShortcuts` для настройки горячих клавиш

### 4. Темная тема
- Полная поддержка темной темы через CSS переменные
- Переключатель темы в header
- Автоматическое определение системных настроек
- Сохранение выбора темы в localStorage
- Хук `useTheme` для управления темой

### 5. Расширенная статистика
- Компонент `StatisticsDashboard` с графиками
- Топ пивоварен по количеству позиций (Bar Chart)
- Распределение по стилям пива (Pie Chart)
- Распределение по форматам упаковки
- Общая статистика: средняя цена, позиции с остатками, с описанием

### 6. Drag & Drop для заказов
- Перетаскивание позиций в заказе
- Визуальная обратная связь при перетаскивании
- Библиотека `react-dnd` для drag & drop функциональности

### 7. Контекстное меню
- Компонент `ContextMenu` для таблиц
- Правый клик по строке таблицы
- Быстрые действия: редактировать, выбрать, копировать, экспортировать
- Показ клавиатурных сокращений в меню

### 8. Сохранение настроек
- Хук `useLocalStorage` для работы с localStorage
- Утилиты `settings.js` для управления настройками
- Автоматическое сохранение фильтров
- Сохранение выбора темы

### 9. Поиск с автодополнением
- Компонент `SearchInput` с подсказками
- Автодополнение из текущих данных
- Навигация по подсказкам с клавиатуры
- Debounce для оптимизации

### 10. Экспорт данных
- Компонент `ExportButton` для экспорта
- Экспорт в CSV формат
- Экспорт в JSON формат
- Готовность к экспорту в Excel

### 11. Обработка ошибок
- Retry механизм для API запросов
- Утилиты `errorHandler.js` для обработки ошибок
- Понятные сообщения об ошибках
- Автоматические повторные попытки

### 12. Улучшенные анимации
- Плавные переходы между вкладками
- Анимации появления элементов
- Hover эффекты
- Анимации загрузки
- Библиотека `framer-motion` для всех анимаций

## 📦 Новые библиотеки

- `react-dnd` и `react-dnd-html5-backend` - для drag & drop

## 🔧 API эндпоинты

### Новые эндпоинты:
- `GET /api/orders/` - список всех заказов
- `GET /api/orders/<id>/` - детали заказа
- `PATCH /api/items/bulk_update/` - массовое обновление
- `POST /api/items/bulk_delete/` - массовое удаление
